# Attribution and source boundary

- Overall autonomous-drone system: team course project.
- Sangheon's included scope: RealSense/helipad vision, depth-derived target output, Uno Q application integration, Bridge forwarding, and flight-log diagnosis.
- Excluded: team flight-controller/STM source, airframe CAD, vendor libraries, trained model weights, calibration outputs, raw datasets/videos, runtime telemetry, and private logs.
- The selected application files are presented for portfolio review without a new reuse license.
- Third-party runtime names (Intel RealSense, NCNN, OpenCV, Arduino) remain property of their respective owners.

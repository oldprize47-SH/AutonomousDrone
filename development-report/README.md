# Development Report Assets

This folder contains curated report assets for the autonomous drone project.

## Contents

| Path | Description |
|---|---|
| `final-report/` | Final project PDF report |
| `system-architecture/` | GCS, hardware, state-machine, and inertia diagrams |
| `experiment-results/` | Report-driven control-result folders for altitude, attitude, position/guidance, vision landing, and GCS monitoring |

The original raw experiment dataset is intentionally not copied here because it is large. This folder keeps the figures and summary CSV files needed to explain the development result in the repository README.

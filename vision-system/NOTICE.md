# 공개 범위 안내

- 전체 자율이동체는 2026년 상반기에 수행한 팀 수업 프로젝트입니다.
- 이 비전 디렉터리에 포함한 박상헌의 범위는 RealSense/헬리패드 데이터 준비, SSDLite 학습·평가, NCNN 검출과 LK 추적, depth 기반 body-FRD 표적 출력, Uno Q 애플리케이션 통합, bridge 전달과 비행 로그 진단입니다.
- 팀 비행제어기/STM 소스, 기체 CAD, 기구·전장 작업, vendor library, 모델 가중치, 개인 calibration, 원본 데이터·영상, runtime telemetry와 비공개 로그는 제외했습니다.
- `docs/images/`의 이미지 4개는 화면에 보이는 개인정보와 메타데이터를 검사했습니다. 구체적인 출처와 프로젝트 경계는 `ATTRIBUTION.md`에 기록했습니다.
- 포함한 응용 코드와 이미지는 포트폴리오 검토를 위한 것이며 공동 학술 결과물에 새로운 재사용 라이선스를 부여하지 않습니다.
- Intel RealSense, NCNN, OpenCV, PyTorch, TorchVision, Albumentations, NumPy, Matplotlib과 Arduino 관련 구성 요소는 각 권리자의 조건을 따릅니다.
